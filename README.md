# 🏥 종합 의료 관리 서비스

저희 종합 의료 관리 서비스는 환자, 병원, 약국을 하나의 플랫폼으로 통합하여 의료 경험을 혁신하고 효율적인 의료 관리를 제공하는 프로젝트입니다.

## 👥 팀원
- 변선우 🧑  
- 김경민 👲  
- 임회연 👩  

##  기굴 스택

###  사용 언어 및 도구

| 카테고리       | 기술/도구                                                                                                  |
|--------------|-----------------------------------------------------------------------------------------------------------|
| 프론트엔드     | HTML5, CSS3, JavaScript                                                                                  |
| 백엔드        | PHP, MySQL (데이터베이스 관리)                                                                            |
| API          | Kakao Map API (병원/약국 검색 및 지도 기능), 공공데이터포털 병원정보 (www.data.go.kr)                         |
| 데이터 관리    | SQL (데이터베이스 쿼리)                                                                                  |

## 📋 프로젝트 개요
- 🚶 환자 대기 시간 단축  
- 📝 디지털 처방전 활성화  
- 🌿 종이 사용량 절감으로 친환경 실천  

본 시스템은 병원, 약국, 환자를 통합하여 의료 기록의 효율적인 관리, 처방전 업로드/다운로드, 사용자 리뷰를 가능하게 하여 전반적인 의료 경험을 향상시킵니다.

## 🎯 프로젝트 목표
- 의료 서비스 통합: 환자, 병원, 약국 데이터를 원활하게 관리할 수 있는 통합 플랫폼 제공  
- 대기 시간 단축: 의료 시설의 대기 시간을 최소화하기 위한 프로세스 간소화  
- 디지털 처방전 관리: 환자가 안전하게 처방전을 관리하여 종이 소비량 절감  

## 🏥 사용자 요구사항

### 👤 환자 요구사항
- 간편한 회원가입: 이름과 주민등록번호로 간편하게 회원가입  
- 의료 정보 접근: 정확한 치료를 위해 처방전 및 의료 기록 열람 가능  
- 리뷰 시스템: 병원 및 약국에 대한 리뷰를 열람하고 작성하여 피드백 공유  

### 🏨 병원/약국 요구사항
- 환자 정보 접근: 안전한 로그인 후 환자 정보에 쉽게 접근 가능  
- 처방전 관리: 의료 전문가가 처방전을 안전하게 업로드 및 관리  
- 피드백을 통한 개선: 환자 리뷰를 활용하여 서비스 품질 향상  

## 🔐 보안 기능
- 의료기관 등록 필수: 병원/약국 등록 시 보안 규정 준수를 위해 사업자 등록증 업로드 필수  
- 처방전 보안: 개인 정보 보호를 위해 처방전은 다운로드 후 데이터베이스에서 자동 삭제  

## 주요 기능
-  회원가입 및 로그인: 환자, 병원, 약국의 회원가입을 지원하며 역할 기반 접근 제어 제공  
-  병원/약국 검색: 병원 및 약국을 검색하고, 리뷰를 확인하며, 운영 시간과 같은 상세 정보를 조회할 수 있는 대화형 지도 제공  
-  처방전 관리: 환자가 민감한 데이터를 신중하게 관리하며 처방전을 안전하게 업로드 및 다운로드 가능  
-  리뷰 시스템: 환자가 병원 및 약국에 대한 피드백을 열람하고 남길 수 있어 리뷰를 기반으로 한 서비스 개선 가능
